## About the Project

Password Generator is a small web application that creates random passwords using a combination of uppercase letters, lowercase letters, numbers, and special characters.

Users can choose the desired password length and generate multiple password options at once.

## Features

- Generate random passwords
- Custom password length selection
- Generates multiple password options
- Uses a combination of:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters
- Simple interactive interface
